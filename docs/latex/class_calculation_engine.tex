\doxysubsection{Detailed Description}
Performs mathematical calculations and logs their results. 

The \doxylink{class_calculation_engine}{Calculation\+Engine} uses a \doxylink{class_logger}{Logger} object to report when a calculation starts and to display its result. This example provides a power operation.
